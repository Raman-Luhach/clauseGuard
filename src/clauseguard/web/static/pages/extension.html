What it does

The full analysis, without leaving the page.

Detects the type

Reads the page's main content and pre-selects the document type. You can change it.

Highlights in place

Flagged clauses are coloured by severity on the page. Hover for the category and explanation.

Full report

Opens every flag in a tab: clause text, explanation, risk group, confidence and protections.

Right-click a selection

Select any text, right-click, and choose “Analyse selected text with ClauseGuard”.

Install in two minutes

Load it into your browser

  1. Download and unzip

    Use the button above, then unzip clauseguard-extension.zip. Keep the folder somewhere permanent.

  2. Open the extensions page

    Go to chrome://extensions (or edge://extensions) and switch on Developer mode, top right.

  3. Load unpacked

    Click Load unpacked and choose the unzipped clauseguard-extension folder.

  4. Pin it and try it

    Pin ClauseGuard from the puzzle-piece menu, open a terms of service page and click the button. It connects to the ClauseGuard server on your own computer (http://127.0.0.1:8000) by default; to use this server instead, enter in the extension's Settings.

Permissions

It asks for as little as possible.

No access to other tabs or to your browsing history, and nothing runs in the background. Pages the browser protects, such as chrome:// pages and the Web Store, can't be read; for PDFs, use the web analyser instead.
